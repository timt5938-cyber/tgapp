# ✍️ Telegram Handwritten Conspectus Studio & Bot

Полноценное приложение Telegram Mini App и Telegram-бот, превращающие любой входящий материал (текст, голосовые сообщения лекций, фото слайдов или страниц учебника) в **реалистичные рукописные конспекты** на тетрадных листах (клетка 5 мм, линейка, поля, колебания строк, нажим чернил, текстовыделители и формулы в рамках) с прямой отправкой готового многостраничного PDF в чат Telegram.

---

## 🌟 Ключевые возможности

1. **Telegram Mini App (Студия конспекта):**
   - Интерактивный предпросмотр страниц в реальном времени с зумом.
   - Выбор тетради: классическая студенческая клетка 5 мм, линейка, чистый лист.
   - Красные тетрадные поля (слева/справа).
   - Выбор чернил: синяя шариковая ручка, черная гелевая, фиолетовая чернильная, красная.
   - Регулировка естественности: ползунок неровности строк (дрожание руки), вариация наклона букв, студенческие хайлайтеры для определений и формулы в рамках.
   - Готовые темы лекций для тестирования в 1 клик.

2. **Интеллектуальная обработка через Google Gemini:**
   - **Режим «Умный конспект»**: сжатие лекции, удаление воды, студенческие сокращения (`т.к.`, `т.е.`, `след-но`), выделение главного (`[ВАЖНО]`, `[ОПР]`, `[ФОРМУЛА]`).
   - **Режим «Слово в слово»**: перенос текста без сокращений с исправлением опечаток.
   - Поддержка голосовых сообщений (бот слушает аудио лектора и сразу конспектирует).
   - Поддержка фотографий слайдов презентаций и страниц книг.

3. **Калибровка персонального почерка (OpenCV):**
   - Написание от руки на обычном чистом листе А4: 1) Заглавные буквы (А-Я), 2) Строчные буквы (а-я), 3) Цифры (0-9). Никаких шаблонных бланков.
   - Фото листа со смартфона $\rightarrow$ автоматическое выравнивание перспективы через гомографию $\rightarrow$ сегментация и изоляция персональных глифов пользователя.

4. **База данных и облако Supabase:**
   - Проект `tgapp` (`https://faxtkubhxjesghpduiba.supabase.co`).
   - Таблицы `user_profiles`, `user_fonts`, `conspectuses`.
   - Публичный бакет `conspectus-assets` для хранения бланков и сгенерированных PDF.

5. **Прямая доставка в Telegram:**
   - Скомпилированный многостраничный A4 PDF документ отправляется прямо в личные сообщения Telegram с превью первой страницы.

## 🚀 Быстрый запуск

### Вариант 1: Единый запуск в 1 команду (Рекомендуется)

```bash
python run.py
```
> Скрипт автоматически проверит зависимости, запустит FastAPI-сервер и Telegram-бота на `http://localhost:8000`. Фронтенд отдаётся напрямую с бэкенда.

### Вариант 2: Запуск с HTTPS-туннелем для Telegram со смартфона

Telegram Mini App требует HTTPS. Если у вас установлен `cloudflared` или `ngrok`:

```bash
python run.py --tunnel
```
Скрипт поднимет безопасный публичный туннель `https://xxxx.trycloudflare.com` и выведет ссылку в консоль.

### Вариант 3: Режим разработки (Hot-reload)

```bash
python run.py --dev
```
- Backend (FastAPI + Bot) на `http://localhost:8000` (с автоперезагрузкой при изменении Python-кода).
- Frontend (Vite) на `http://localhost:5173` (с мгновенным HMR).

## 🤖 Подключение WebApp к Telegram-боту

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте команду `/mybots` и выберите вашего бота (токен: `8941440413:AAHQob9S6KPZBPaJS3czdkY4pCM3rB68Nmc`).
3. Выберите **Bot Settings** $\rightarrow$ **Menu Button** $\rightarrow$ **Configure menu button**.
4. Вставьте вашу публичную HTTPS-ссылку (полученную через `--tunnel` или ваш хостинг/домен).
5. Также в файле `.env` укажите эту ссылку в параметре `MINI_APP_URL=https://...`.

## ⚙️ Настройка Gemini API

Google предоставляет бесплатные ключи через [Google AI Studio](https://aistudio.google.com).
- Вы можете указать ключ в файле `.env`: `GEMINI_API_KEY=AIzaSy...`
- Либо любой пользователь может указать свой ключ прямо в интерфейсе Mini App в разделе «Настройки».
- *(Если ключ не указан, система использует встроенный локальный алгоритм конспектирования)*.
